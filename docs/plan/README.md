## GPU 成本估算（单卡 2.43 元/h，双卡 4.86 元/h）

| 阶段 | 卡数 | 小时 | 金额 |
|---|---|---|---|
| D0-A 无卡准备 | 0 | ~12 | 极低 |
| D0-B 有卡冻结 | 1 | 1.5 | 3.6 |
| D1 harness 联调 | 1 | 2 | 4.9 |
| D2 基线 | 1 | 3 | 7.3 |
| D3 训练 | 1 | 8 | 19.4 |
| D4–D5 主线 | 2 | 20 | 97.2 |
| D6 对照 | 2 | 10 | 48.6 |
| D7 复跑 | 1 | 1.5 | 3.6 |
| **合计** | | **46 h** | **≈ 185 元** |

两条成本结论：

1. **双卡不多花钱**。双卡 4.86 元/h 跑 20 h = 97 元；同样工作量单卡要 40 h 也是 97 元。
   成本相同，但双卡快一倍，且能同时刻跑 A/B 消除时间漂移噪声。**D4–D6 用双卡是纯赚。**
2. **无卡准备的真正价值不是省那 14 元**，而是 A.8 算出的**共享前缀占比**：
   它用 0 元的 CPU 计算，提前验证 D4–D5 那 **97 元双卡实验**的前提是否成立。

## Gate 总表（不过就停下来，不要带着问题往前走）

| Gate | 阶段 | 判据 | 不过怎么办 |
|---|---|---|---|
| G0 | D0 | vLLM 能加载 Qwen3-0.6B 并返回 `logprobs` | 停工排查环境，不要写业务代码 |
| G1 | D1 | 端到端跑通一次，产出**格式合法**的结果 JSON | 修 harness，D2 不许开始 |
| G2 | D2 | `recall@32` > 0.6 | 检查 prompt / instruction 拼装，不是模型问题 |
| G3 | D3 | 微调后 `MAP@25` 显著优于 zero-shot | 训练不达标就**放弃训练**，全程用 zero-shot，把时间还给主线 |
| G4 | D4 | E1 的 prompt 结构消融跑出 **≥ 2× 吞吐差异** | 主线立不住，立刻改方向，当天决策 |
